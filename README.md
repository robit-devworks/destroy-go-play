# デストロイ碁 - DESTROY GO（無料版）

石を取るとド派手に壊れる囲碁ゲームです。1 台のスマホやパソコンを 2 人で挟んで遊べるほか、コンピューター（強さ 1〜9）とも対戦できます。

**▶ 遊ぶ：https://robit-devworks.github.io/destroy-go-play/**

- ふつうの囲碁と、HP を削り合う「デストロイルール」で遊べます
- 無料版の演出は「デストロイ」と「氷」の 2 種類です（ほかの演出は製品版で準備中）
